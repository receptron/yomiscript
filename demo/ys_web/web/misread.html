YomiScript：LLM が読みを決める音声合成を、ブラウザーで

GitHub（仕様とコード） Hugging Face（Kokoro のモデル） デモ：駅のアナウンス デモ：青空朗読文庫

Kokoro などのオープンソース TTS は音質が大きく向上しましたが、日本語では「市場（いちば／しじょう）」のように文脈で読みが変わる語を読み間違えることがあります。読み分けの難しい語を集めた70文のテストでは、元の Kokoro の読みの正解率は 32.9% でした。

YomiScript は、この前処理（読み手、Yomite）を LLM に任せます。LLM が発音記号ベースのスクリプトを書き、語り手（Katarite）がそれを音声にします。文章を書いた LLM がそのまま読み方も書くため、同じテストで読みの正解率は 98.6%（Claude）と 100%（Codex）でした（各1回の評価で、正解の読みは暫定です）。読みのための追加の LLM 呼び出しは不要で（出力するトークンは増えます）、Claude Code や Codex で生成すれば API キーも要りません。

読みの判断を LLM に任せたことで、語り手は軽量になりました。Kokoro ベースの語り手は約160 MB で、サーバーなしにブラウザーの中だけで動きます。このページの YomiScript の音声も、いまこのブラウザーの中で生成しています。

Kokoro ベースの語り手を提供しますが、Supertonic 用の語り手もあり、置き換えは自由です。言語に依存しない公開仕様として、オープン TTS の共通の形式を業界に提案したいと考えています。

YomiScript の音声は、録音ではありません。ボタンを押すたびに、このブラウザーの中で Kokoro ベースの語り手が生成しています（サーバーには送りません）。生成にかかった時間と音声の長さを、それぞれの文の下に表示します。オリジナルの Kokoro の音声は、比較のために事前に録音したものです。
